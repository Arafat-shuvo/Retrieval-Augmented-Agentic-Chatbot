# Retrieval-Augmented Agentic Chatbot

An intelligent Agentic Chatbot designed to provide context-aware responses through Retrieval-Augmented Generation (RAG) and AI-driven question answering.

## Overview

This project demonstrates an intelligent chatbot that combines Retrieval-Augmented Generation (RAG) with an agentic approach to deliver relevant and context-aware responses.

The frontend is developed using **JavaScript, React, and Vite**, providing a modern and responsive user interface for interacting with the chatbot.

## Technologies Used

### Frontend

- React.js

- CSS3

- Artificial Intelligence

- Interactive chatbot interface

## Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/Arafat-shuvo/Retrieval-Augmented-Agentic-Chatbot.git
```

### 2. Navigate to the Project Directory

```bash
cd Retrieval-Augmented-Agentic-Chatbot
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start Development Server

```bash
npm run dev
```

### 5. Build for Production

```bash
npm run build
```

### 6. Preview Production Build

```bash
npm run preview
```

## React + Vite

This project uses Vite to provide a fast development environment with Hot Module Replacement (HMR).

Official React plugins:

- [@vitejs/plugin-react](https://github.com/vitejs/vite-plugin-react) – Babel-based Fast Refresh.
- [@vitejs/plugin-react-swc](https://github.com/vitejs/vite-plugin-react-swc) – SWC-based Fast Refresh.
